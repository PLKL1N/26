# Node CPU (%)
## ALL Node CPU
Query: 100 - (avg by(node) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

## Node Memory (%)
Query: avg by(node) (100 * (1 - ((avg_over_time(node_memory_MemFree_bytes[5m]) + avg_over_time(node_memory_Cached_bytes[5m]) + avg_over_time(node_memory_Buffers_bytes[5m])) / avg_over_time(node_memory_MemTotal_bytes[5m]))))

## Available Nodes
Query: sum by (label_eks_amazonaws_com_nodegroup) (kube_node_status_condition{condition="Ready", status="true"} * on(node) group_left(label_eks_amazonaws_com_nodegroup) kube_node_labels)
Legend: {{label_eks_amazonaws_com_nodegroup}}

# Pod
## ALL Pod CPU
Query: sum by (pod) (rate(container_cpu_usage_seconds_total{image!=""}[5m]))
Legend: {{pod}}

## ALL Pod Memory
Query: sum by (pod) (container_memory_working_set_bytes{image!=""})
Legend: {{pod}}

## ALL Pending Pods
Query: sum(kube_pod_status_phase{phase="Pending"})

## ALL Pod Restarts
Query: sum by (pod) (rate(kube_pod_container_status_restarts_total[5m]))

# Application Traffic
## App Request Count
Query:
A: SELECT SUM("app/RequestCount") FROM "wsc2026-metrics"
B: FILL(m1, 0)
B Label: Requests/min

## App Response Time
Query:
filter @message like /"duration":/
| parse @message '"duration":"*ms"' as duration
| stats avg(replace(duration, "ms", "") + 0) as avg_durations by bin(1m)
